# Portfólio Pessoal – Landing Page

Este projeto consiste no desenvolvimento de uma landing page funcional criada como parte do desafio prático do curso de Introdução à Programação Front-End e Back-End.

O objetivo da atividade é consolidar em um único espaço digital informações sobre trajetória profissional, habilidades técnicas, habilidades comportamentais e projetos desenvolvidos (ou em desenvolvimento), aplicando os conhecimentos adquiridos ao longo do curso.

## Sobre o Estudante

Sou Engenheiro Mecânico e, há aproximadamente dois anos, venho direcionando meus estudos para a área de programação. O interesse por desenvolvimento web surgiu inicialmente como curiosidade, mas evoluiu para um objetivo profissional estruturado.

Atualmente estudo HTML, CSS e JavaScript, aplicando conceitos de organização, estrutura e lógica na construção de interfaces web. Possuo projetos privados em desenvolvimento que serão publicados conforme minha evolução técnica.

## Objetivo do Projeto

- Construir uma landing page responsiva;
- Organizar informações pessoais e profissionais;
- Apresentar projetos demonstrativos;
- Aplicar HTML, CSS e JavaScript de forma estruturada;
- Desenvolver um projeto executável sem erros críticos.

## Tecnologias Utilizadas

- HTML5 (estrutura semântica)
- CSS3 (layout responsivo, grid, estilização)
- JavaScript (interação do menu responsivo)

## Estrutura do Projeto

- `index.html` → Estrutura principal da página
- `styles.css` → Estilização completa do layout
- `script.js` → Funcionalidades em JavaScript
- `assets/` → Imagens dos projetos

## Responsividade

A página foi estruturada utilizando layout flexível e grid, garantindo adaptação para diferentes tamanhos de tela, incluindo dispositivos móveis.

## Considerações Finais

Este projeto representa um marco inicial na construção do meu portfólio profissional na área de tecnologia. A proposta é evoluir continuamente a estrutura da aplicação, substituindo projetos demonstrativos por projetos reais e ampliando funcionalidades conforme avanço nos estudos.

## Como executar
1. Baixe/extraia a pasta do projeto.
2. Abra o arquivo `index.html` no navegador (Chrome, Edge ou Firefox).
3. Em telas menores (mobile), utilize o botão ☰ para abrir e fechar o menu.
